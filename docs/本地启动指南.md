# 本地启动指南

本文说明如何在本地把项目跑起来，包含 Docker 一键启动与手动启动两种方式。

---

## 一、环境要求

| 依赖 | 版本 | 说明 |
|---|---|---|
| JDK | 17+ | 项目使用 Java 17 编译 |
| Maven | 3.8+ | 或直接使用仓库自带的 `mvnw` |
| Docker | 20.10+ | 仅使用方式一时需要 |
| MySQL | 8.0+ | 也可由 Docker 提供 |
| Redis | 6+ | 也可由 Docker 提供 |
| MongoDB | 5+ | 也可由 Docker 提供 |

---

## 二、方式一：Docker Compose（推荐）

### 1. 准备环境变量

复制示例文件并修改：

```bash
cp .env.example .env
```

**必须修改的项**（`MYSQL_PASSWORD` 已改为必填，未设置会直接报错退出）：

```ini
MYSQL_USERNAME=root
MYSQL_PASSWORD=你的数据库密码
MYSQL_DATABASE=mainshi_agent
```

如需使用 AI 能力，还需填写：

```ini
XUNFEI_APP_ID=
XUNFEI_API_KEY=
XUNFEI_API_SECRET=

SPRING_AI_OPENAI_API_KEY=
SPRING_AI_OPENAI_BASE_URL=https://api.openai.com
SPRING_AI_OPENAI_MODEL=gpt-4o-mini
```

### 2. 启动

```bash
docker compose up -d
```

Compose 会自动完成：

- 启动 MySQL / MongoDB / Redis
- **按顺序执行 5 个初始化 SQL**（`table.sql` → `admin_permission.sql` → `agent_properties.sql` → `ai_properties.sql` → `t_user.sql`）
- 构建并启动后端服务

### 3. 查看状态

```bash
docker compose ps
docker compose logs -f backend
```

服务端口：后端 `8002`、MySQL `3306`、MongoDB `27017`、Redis `6379`。

## 三、方式二：手动启动（便于 IDE 调试）

### 1. 先启动依赖服务

可以只用 Docker 拉起三个中间件：

```bash
docker compose up -d mysql mongo redis
```

也可以使用本机已安装的 MySQL / MongoDB / Redis。

### 2. 初始化数据库

若未使用 Docker 自动初始化，需手动执行 SQL（**注意顺序**）：

```bash
mysql -u root -p -e "CREATE DATABASE mianshi_agent DEFAULT CHARSET utf8mb4;"
mysql -u root -p mianshi_agent < admin/src/main/resources/sql/table.sql
mysql -u root -p mianshi_agent < admin/src/main/resources/sql/admin_permission.sql
mysql -u root -p mianshi_agent < admin/src/main/resources/sql/agent_properties.sql
mysql -u root -p mianshi_agent < admin/src/main/resources/sql/ai_properties.sql
mysql -u root -p mianshi_agent < admin/src/main/resources/sql/t_user.sql
```

> `ai_properties.sql` 中的 API Key 已替换为占位符（`YOUR_SPARK_API_KEY` / `YOUR_DEEPSEEK_API_KEY`），
> 需要替换为真实值，或改到配置中心 / 环境变量中维护。

### 3. 配置连接信息

`admin/src/main/resources/application.yaml` 已支持环境变量覆盖，也可直接修改：

| 变量 | 说明 | 默认值 |
|---|---|---|
| `SERVER_PORT` | 服务端口 | `8002` |
| `MYSQL_HOST` / `MYSQL_PORT` | MySQL 地址 | `127.0.0.1` / `3306` |
| `MYSQL_DATABASE` | 数据库名 | `mainshi_agent` |
| `MYSQL_USERNAME` / `MYSQL_PASSWORD` | 数据库账号 | `root` / 需自行配置 |
| `REDIS_HOST` / `REDIS_PORT` | Redis 地址 | `127.0.0.1` / `6379` |
| `MONGODB_HOST` / `MONGODB_PORT` | MongoDB 地址 | `127.0.0.1` / `27017` |
| `MONGODB_DATABASE` | MongoDB 库名 | `xunzhi_agent` |

### 4. 编译并运行

```bash
mvn clean package -DskipTests
java -jar admin/target/*.jar
```

或在 IDE 中直接运行启动类。

---

## 四、启动成功的判断

- 控制台出现 `Started ... in x seconds`
- 访问 `http://localhost:8002` 有响应
- `docker compose ps` 中 `backend` 状态为 `running`

---

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `MYSQL_PASSWORD` 未设置，compose 直接退出 | 已移除默认弱密码，改为必填 | 在 `.env` 中设置 `MYSQL_PASSWORD` |
| 启动报「AI API Key 未配置」 | 未填 AI 密钥 | 配置 `XUNFEI_API_KEY` 或 `SPRING_AI_OPENAI_API_KEY` |
| 连不上 MySQL | 端口占用 / 密码不符 | 检查 `3306` 是否被本机 MySQL 占用 |
| 中文乱码 | 字符集不一致 | 确认建库使用 `utf8mb4` |
| MongoDB 连接失败 | 未启动或开了认证 | 确认 `27017` 可访问 |
| 前端页面空白 | 仅启动了后端 | 需另行启动前端工程 |

---

## 六、安全提示

- **不要把真实密钥提交到仓库**。`.env` 已在 `.gitignore` 中排除。
- `MYSQL_PASSWORD` 已改为必填，避免误用弱默认密码启动。
- 若曾将密钥提交到公开仓库，请到对应控制台**作废并重建**该密钥。
